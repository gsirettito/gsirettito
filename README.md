### Telecommunications & Electronics Engineer | C# / .NET Developer | IoT & Microcontrollers Enthusiast

I'm a **Telecommunications and Electronics Engineer** from the **Universidad de Oriente, Cuba** (Class of 2020). I love bridging the gap between hardware and software to create useful, real-world solutions.
